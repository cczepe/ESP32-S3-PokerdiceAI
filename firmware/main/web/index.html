Current connection

Join the home Wi-Fi

Needed for the Pokerdice Trainer. The board is then reachable at http://pokerdice.local (or its IP address). The password is stored only on the board.

2.4 GHz networks only. If the home Wi-Fi is not reachable for 30 s, the hotspot comes on as well.

Hotspot only

For playing without a home network: phones join the hotspot Pokerdice and the page opens by itself.

Also possible on the board: hold the BOOT button for 5 seconds.
