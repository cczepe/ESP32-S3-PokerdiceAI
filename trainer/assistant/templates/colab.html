How the package gets to Google Drive and Colab

Important: do not unpack the ZIP file. The notebook unpacks it itself. (If you uploaded an unpacked folder, Google Drive would create a second folder with the same name instead of merging.)

The first time:

  1. drive.google.com → “My Drive” → New → Folder “{{ drive }}”, inside it a folder “packages”.
  2. Drag the newest ZIP file Colab_{{ folder }}_….zip from {{ packages_folder }} into {{ drive }} → packages.
  3. Open the notebook 1_setup_{{ folder }}_….ipynb: colab.research.google.com → File → Upload notebook → choose the .ipynb file.
  4. In Colab: Runtime → Change runtime type → L4 GPU (or T4), then run the cells in order. The notebook unpacks the package; afterwards all notebooks are in Drive under {{ drive }} → notebooks.

Later (new photos, new test images, new version): create a new package, upload the ZIP file to packages again, double-click the matching notebook in Drive {{ drive }} → notebooks (→ “Open with Google Colaboratory”) and run everything. The newest package is unpacked automatically; renders, crops and trained models are kept.

If “Open with Google Colaboratory” does not appear: right click → Open with → Connect more apps → search for “Colaboratory” and add it.

Important in practice

  • End the session at the end: a connected Colab session uses compute units even when it does nothing. Each notebook ends with the cell “End session”: set END_SESSION = True and queue it with ▶ - it runs after all other cells. Or by hand: Runtime → Disconnect and delete runtime.
  • Colab does not guarantee how long a session runs. A session can end after several hours (also with a paid plan, or when the compute units run out). Nothing is lost: open the notebook again and Run all - finished chunks, crops and training runs are skipped, started ones continue. The preview in 1_setup measures how long the full render takes - if that is many hours, 2_render and the training in separate sessions is the safer plan.
  • Do not upload a new package while something is running in Colab - at the next start scripts and notebooks in Drive are replaced.
  • Download export only when the detector and the classifier have both been exported - before that it is incomplete.
