Python environment .venv

An own, self-contained Python environment only for this repository, in {{ REPO|path('.venv') }}. It uses Python 3.11, because esp-ppq (to convert the models for the camera board) can only be installed there.

If you see this page, the trainer is running already - the setup is done. The page is for looking things up (e.g. if you have to create the environment again).

Create it (once)

Windows (PowerShell in the repository folder):

cd "{{ REPO }}"
powershell -ExecutionPolicy Bypass -File setup.ps1

Linux / macOS:

cd "{{ REPO }}"
./setup.sh

The script creates .venv with Python 3.11 and installs everything from trainer/requirements.txt (Flask, anthropic, OpenCV, onnxruntime, torch CPU, esp-ppq …). The first run takes a few minutes.

Start the trainer

Easiest: double-click start.bat (Windows) or run ./start.sh. Or directly:

cd "{{ REPO }}"
.venv\Scripts\python.exe trainer\assistant\app.py

Quit with Ctrl+C in the terminal window. All start options: .venv\Scripts\python.exe trainer\assistant\app.py --help (Linux/macOS: .venv/bin/python trainer/assistant/app.py --help)

Common errors

MessageSolution
“No suitable Python runtime found” for py -3.11 Python 3.11 is not installed. Install it from python.org (it can live next to other versions). Installed versions: py -0
“… cannot be loaded because running scripts is disabled” Start the script as shown above with -ExecutionPolicy Bypass, or once Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
“ModuleNotFoundError: No module named 'flask'” The trainer was started with the wrong Python. Use .venv\Scripts\python.exe or start.bat.
Port 5000 in use Choose another port: … app.py --port 5050
